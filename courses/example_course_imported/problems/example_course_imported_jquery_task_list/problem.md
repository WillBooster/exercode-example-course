## 問題文

Railsアプリの画面で、入力したタスクを一覧に追加するjQueryコードを作成します。
`app/javascript/task_list.js`の`initializeTaskList`関数を完成させてください。

画面には次の要素が用意されています。

- タスク名を入力する`id="task-title"`の入力欄
- タスクを追加する`id="add-task"`のボタン
- タスクを表示する`id="task-list"`のリスト

`initializeTaskList`関数が呼ばれた後、「追加」ボタンを押すと、入力値の前後から空白を取り除いた文字列を新しい`li`要素のテキストとしてリストの末尾へ追加してください。追加後は入力欄を空にしてください。

空白を取り除いた入力値が空文字列になる場合は、リストへ何も追加しないでください。

## 制約

- jQueryを使って実装すること。
- `initializeTaskList`関数をエクスポートすること。
- 関数名とファイル名を変更してはいけない。
- 入力値は文字列である。
- 入力値の長さは、前後の空白を含めて$0$文字以上$100$文字以下である。
- 入力値はHTMLではなくテキストとして表示すること。

---

## 入力

標準入力は使用しません。
採点時にjsdom上で入力値を設定し、jQueryでクリックイベントを発生させます。

## 出力

標準出力は使用しません。
全てのDOM操作テストに成功すると正解です。

---

## サンプルケース

入力欄へ`買い物に行く`と入力して「追加」ボタンを押すと、タスク一覧の末尾へ次の要素が追加されます。

```html
<li>買い物に行く</li>
```
