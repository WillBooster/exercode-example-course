## 実行できるコードブロック

Python や Java などのプログラミング言語を指定したコードブロックは、教材上でそのまま編集・実行できます。
学生は `実行` ボタンを押して、コードブロックの下に表示される標準出力などの実行結果を確認できます。

```python
a = 3
b = 5
print(a + b)
```

## 標準入力を受け取るコードブロック

`input()` のように標準入力を読むプログラムでは、言語の後ろに `stdin` を付けます。
すると標準入力の入力欄が最初から開いた状態で表示されます。

さらに、直後に `stdin` のコードブロックを置くと、その内容が入力欄の初期値になります。
学生は初期値を書き換えて、実行結果の変化を確かめられます。

```python stdin
a = int(input())
b = int(input())
print(a + b)
```

```stdin
3
5
```

`stdin` を付けなくても、学生は `標準入力` ボタンから入力欄を開けます。
Python の `input()` や Java の `Scanner` のように標準入力の不足がエラーになるプログラムでは、入力欄を閉じたまま実行すると、標準入力が必要である旨のメッセージとともに入力欄が開きます。

```python
name = input()
print('Hello, ' + name + '!')
```

## 実行しないコードブロック

コードの断片など、実行させたくないコードブロックには `no-execute` を付けます。
通常のコードブロックとして表示されます。

```python no-execute
print(a + b)
```
