## 実行できるコードブロック

Python や Java などのプログラミング言語を指定したコードブロックは、教材上でそのまま編集・実行できます。
学生は `実行` ボタンを押して、コードブロックの下に表示される標準出力などの実行結果を確認できます。

```python
a = 3
b = 5
print(a + b)
```

## 標準入力を受け取るコードブロック

`input()` のように標準入力を読むプログラムでは、言語の後ろに `stdin` を付けます。
すると標準入力の入力欄が表示され、学生は入力欄に値を入れてから実行できます。
本文に入力例を書いておくと、学生が入力欄に何を入れればよいか分かりやすくなります（例: 1行目に `3`、2行目に `5` を入力）。

```python stdin
a = int(input())
b = int(input())
print(a + b)
```

標準入力を使わせるかどうかは教材作成者が決めます。
`stdin` 属性のないコードブロックでは、学生は標準入力を使用できません。
次のように標準入力を読むコードを実行すると、標準入力を使用できない旨のメッセージが表示されます。

```python
name = input()
print('Hello, ' + name + '!')
```

## 実行しないコードブロック

コードの断片など、実行させたくないコードブロックには `no-execute` を付けます。
通常のコードブロックとして表示されます。

```python no-execute
print(a + b)
```
